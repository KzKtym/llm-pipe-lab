## 読むときの注意

- **数字は測定当時のもの**である。反復測定の幅については `../MEASUREMENT.md` 2節を参照
- **「仕込み」と「発見」を区別して読むこと。** `demo_sales` の7つの落とし穴は
  設計時に自分たちで仕込んだものであり、分析で発見したものではない
- 記録中の `exp_N` は実験の通し番号、`qNNN` / `sNNN` は評価データの問題IDである
  （`../../sample/sales/` 配下の JSON に対応する）
